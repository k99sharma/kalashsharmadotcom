# Personal Portfolio Website

This repository contains the source code for my personal portfolio website.  
It showcases my work as a Software Engineer, selected projects, and ways to get in touch.

---

## ✨ Features

- Modern, responsive UI
- Accessibility-first layout (semantic HTML, landmarks)
- Performance-optimized with lazy loading
- Modular component architecture
- Interactive sections for projects, skills, and experience
- Map integration using Leaflet
- Clean SEO setup (meta tags, robots.txt)

---

## 🛠 Tech Stack

- **Frontend:** React, TypeScript
- **Styling:** Tailwind CSS, global CSS
- **UI Library:** Ant Design
- **Maps:** Leaflet + OpenStreetMap
- **Build Tool:** Vite

---

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm / pnpm / yarn

### Install dependencies

```bash
npm install
```

### Run

```bash
npm run dev
```
